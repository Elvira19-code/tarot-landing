# Telegram-бот Taroway

Python 3.12+, python-telegram-bot 22.8. Запуск через long polling: отдельный публичный порт не требуется.

## Настройки

Обязательные переменные окружения: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_OWNER_ID` (числовой ID получателя).
Для ИИ: `CLOUD_RU_API_KEY` либо файл `cloudru.key` в `CREDENTIALS_DIRECTORY` (systemd), иначе `/etc/taroway/cloudru.key`.
Не добавляйте секреты в репозиторий. Владелец должен сначала нажать Start в боте.

## Запуск

Установите зависимости в отдельное виртуальное окружение: `pip install -r requirements.txt`.
После установки переменных окружения запустите `python bot.py`.
Для VPS предусмотрен `taroway-bot.service`: исходники в `/opt/taroway/telegram-bot`, окружение Python в `/opt/taroway/telegram-venv`, секреты в `/etc/taroway/telegram.env` (root, 0600). Запустите `sudo bash install-vps.sh`, затем `sudo python3 /opt/taroway/telegram-bot/configure.py` и повторно `sudo bash install-vps.sh`.
Не запускайте одновременно два процесса с одним токеном.

## Поведение

- Главное меню: гороскоп, карта дня, «Ещё». Второй экран: запись, о нас, назад.
- Знаки зодиака: по два знака и переход к следующим; `/start` возвращает меню.
- Колода: 78 карт, равновероятный выбор; описания символические, без обещаний.
- Гороскоп — общий символический текст, не расчёт натальной карты.
- Вопросы консультанту отправляются в Cloud.ru; имя, контакт и заявка туда не передаются.
- Перед записью запрашивается согласие и подтверждение возраста. Контакт передаётся владельцу в Telegram.
- Заявка подтверждается только после успешной отправки владельцу. При сбое доступен повтор.
- Незавершённые заявки хранятся только в памяти и удаляются при перезапуске или `/cancel`.
- Ограничение ИИ: один запрос пользователя в 15 секунд, максимум 1000 символов.

## Проверка

`python -m unittest discover -s . -p "test_*.py"`

После настройки секретов: проверить `/start`, оба экрана меню, 12 знаков, карту дня, запись и доставку владельцу. Реальная проверка Telegram требует токен и ID.
